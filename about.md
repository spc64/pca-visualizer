pca-visualizer is a flexible command-line utility for comparing and displaying different datasets (such as biological data) using principal component analysis (PCA) in both two and three dimensions, written in Python. Visualizations with PCA retain variance between samples while simplifying the amount of axes to their "principal components". pca-visualizer is an extension of "Principal Component Analysis (PCA) on Iris Dataset" (https://scikit-learn.org/stable/auto_examples/decomposition/plot_pca_iris.html).

pca-visualizer displays distance using a normalized tree structure. Samples that cluster near a given node indicate high similarity in their principal components and are likely homogeneous. The number of nodes to plot can be configured. A higher node count granularizes node clusters and may overdiscriminate homogenous samples or create unwanted nodes for insignificant outliers. Likewise, a lower node count generalizes node clusters and may group heterogenous samples if they lack significant variation.

pca-visualizer requires numpy, matplotlib, sklearn (pip install scikit-learn), and elpigraph. pca-visualizer was developed in CentOS Stream 10 for Python 3.12.11. It reads plain text files written in .csv format. It outputs the results on a separate window generated by matplotlib.
